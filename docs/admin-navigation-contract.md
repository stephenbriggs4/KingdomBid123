# FaithBid admin navigation contract

This contract documents the current navigation without deciding Concierge's permanent product placement.

- **Admin Review** is the top-level admin destination for admissions, trust review, project moderation, disputes, and founder review queues.
- **Admin operations** is the protected operational-tool group inside Workspace. It contains Concierge Pilot Operations, Growth Engine research, and the QA Console.
- Concierge appears once in desktop navigation and once in the mobile equivalent. It is not duplicated in the account menu.
- Any decision to move Concierge to a permanent top-level destination remains founder-owned and must not be inferred from this information-architecture cleanup.
